# **QA Compass**

use the image as an example

Create a modern, professional, responsive personal portfolio website for an undergraduate Information Technology student who is looking for Software Quality Assurance / QA Engineer internships and entry-level IT opportunities.

The website should feel professional, clean, modern, and recruiter-friendly. It should showcase my education, technical skills, academic projects, QA/testing knowledge, research project, certifications, resume, and contact information.

## 1. Overall Design

Use a modern technology-focused portfolio design with:

* Clean and minimal UI
* Professional typography
* Plenty of whitespace
* Smooth scrolling
* Subtle animations
* Responsive design for desktop, tablet, and mobile
* Modern cards with subtle hover effects
* Professional dark/light theme toggle
* Accessible color contrast
* No excessive animations
* No unnecessary stock photos
* No fake testimonials
* No fake work experience
* No exaggerated claims

The design should look like a real professional portfolio created by an IT undergraduate, not a generic AI-generated website.

Use a professional color palette based around dark navy/charcoal, white/light backgrounds, and one modern accent color.

Add a sticky navigation bar that becomes slightly blurred/translucent while scrolling.
